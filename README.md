# Shorts Transcriber — refactored

## Что изменено

- Whisper получает короткий prompt меньше лимита Groq.
- Используется `whisper-large-v3`, `temperature=0`, word timestamps.
- Аудио для Whisper создается как mono WAV 16 kHz.
- Тихая речь поднимается компрессией без `silenceremove`.
- Горизонтальное видео масштабируется пропорционально и центрируется crop-ом в 1080x1920.
- ASS создается внутри приложения и не должен редактироваться пользователем.
- Для редактирования возвращаются обычные слова с `id`, `start`, `end`.
- Каждый subtitle event появляется в момент начала конкретного слова, поэтому будущие слова не показываются заранее.

## Запуск

```bash
npm install
```

Создайте переменную окружения:

```bash
GROQ_API_KEY=your_new_key
```

По умолчанию используется официальный URL Groq. Если вы намеренно используете совместимый proxy, задайте его отдельно:

```bash
GROQ_API_URL=https://your-proxy.example/transcriptions
```

Затем:

```bash
npm run build
npm start
```

Новый ключ Groq нужно создать отдельно: прежний ключ был опубликован в исходном файле и считается скомпрометированным.

## Удобный редактор субтитров

Клиенту нужно показывать не `rawAssText`, а `words`:

```json
[
  { "id": 0, "word": "Привет", "start": 0.42, "end": 0.78 },
  { "id": 1, "word": "мир", "start": 0.82, "end": 1.15 }
]
```

На экране это можно представить как список слов на timeline. Пользователь меняет только `word`, а `start` и `end` двигает мышью. Перед approve клиент отправляет обратно `words`, а сервер сам генерирует ASS.

## Ограничение

Ни одна модель не гарантирует идеальную транскрипцию шепота, музыки и речи поверх шума. Для качества важнее всего исходная дорожка, отсутствие тишины в начале фрагмента и правильные границы нарезки.
